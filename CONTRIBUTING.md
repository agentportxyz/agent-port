# Contributing to Agent Port documentation

Use a GitHub issue for a broken link, outdated screenshot, or change to a documented workflow. Include the page, the text or screen you saw, and the wording or behavior you expected.

For a pull request, keep the edit focused. Check service names against the [directory](https://getagentport.xyz/districts) and product steps against the [official docs](https://getagentport.xyz/docs). Screenshots should show public pages or illustrative content. Give each image descriptive alt text and verify relative links before submitting.

Use [Agent Port Support](https://getagentport.xyz/support) for help with an account, delivery, or campaign. Follow the [security policy](SECURITY.md) for sensitive reports.
