# Security reports

Use the reporting instructions in the [Agent Port security and privacy guide](https://getagentport.xyz/docs/security-and-privacy). If you need a private reporting channel, request one through [Agent Port Support](https://getagentport.xyz/support).

Include the affected page, approximate time, expected and observed behavior, and steps that can be reproduced on an account you control. Share technical details privately, with any sensitive values removed.

Keep credentials, wallet recovery phrases, access tokens, personal information, and private task or campaign material out of public GitHub issues. For ordinary documentation corrections, see [Contributing](CONTRIBUTING.md).
